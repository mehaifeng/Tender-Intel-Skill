# 医院官网检索适配器（hosp）

仅在维护或诊断 hosp 检索组件时读取本文件。域名索引本体与其维护流程见[医院官网索引](hospital_sites.md)。

## 定位

打 CCGP 与 PLAP **结构上拿不到**的那部分：医院自己发布的院内遴选、询比、议价、竞价、供应商征集和市场调研。这类采购不走政府采购流程，只挂在医院官网。

实现上不是新写爬虫，而是复用豆包搜索 API 的 `Sites` 白名单——域名来自 `data/hospital_sites.min.json.gz`，按 20 个一批轮转（API 上限）。

## 选域规则

```bash
python scripts/hosp_search.py            # 默认 db>=1，369 个域名，19 批
python scripts/hosp_search.py --min-target 1   # 只打有检验类命中的，149 个，8 批
python scripts/hosp_search.py --limit-sites 200  # 控成本
```

**按 `db > 0` 选（豆包索引到过招采页），不看 `s`（HTTP 可达性）**——两者是独立信号。索引里 27 个 HTTP 抓不到的域名豆包仍有招采产出（南京市第一医院、蚌医大一附院这些站是活的，只是反爬挡住了抓取器）。据 `s=5` 剔除会误杀这批。

`bad=1` 的域名**永不进白名单**——那是被抢注、域名过期或第三方目录站，页面内容不可信（实测落点有体育直播站、股票配资站、TP 钱包下载页）。

**默认用 `--min-db 1` 而不是 `--min-target 1`**：医院采购周期长，按单次普查的 `tg` 筛会把「上季度没采试剂、这季度采了」的医院永久排除在外。省下的 6.6 元/月不值得这个风险。

## Query 只用宽词

默认 `招标`、`试剂` 两个词。医院单站公告量很小，精准词的价值在聚合站那种海量池子里筛，这里上 30 个词纯属浪费额度。

Query 仍受官方「不支持多词搜索」约束，脚本会拒绝含空格的词。

## 三层预筛

原始结果里绝大多数不是本司线索，进队列前过三关：

1. **硬排除**（`EXCLUDE`）——同名异域场景：兽医/畜牧、结核与 γ-干扰素释放、免疫组化二抗、重组蛋白、核酸 PCR，以及公司不做的酶标仪、电泳、洗板机。优先级最高，命中即排除。

   只列「共用词汇但完全是另一回事」的场景，**不列物业/食堂/装修这类**——它们本来就过不了品类关，多写一层反而误伤（第一版把 `维修` 写进来，「免疫分析仪维修保养」被误杀）。

2. **栏目页拦截**（`is_channel_page`）——医院站的招采频道首页标题就叫「招标公告-龙岩市第二医院」「招标-四川省儿童医院」，会被意图词放行但页面上没有任何可核实字段。判据是「找不到具体性标记（项目名/批次/年份/编号）且标题很短」或出现站点导航词。

   宁可放过少量真公告：真公告漏了下次运行还会出现，栏目页则会天天重复占位。

3. **品类信号分两档**（keywords.md §11 方案 B）：
   - `precise` —— 标题或摘要直接命中过敏/自免/细胞因子/方法学
   - `broad` —— 整批检验试剂耗材招采（「2026年医用耗材第三批遴选公告」），目标品类在清单里而不在标题

   **broad 档不可省。** 第一版只认 precise，465 条原始结果只剩 1 条；补上 broad 后是 8 条。医院院内遴选大量是这种形态。

## 候选字段

| 字段 | 取值与理由 |
|---|---|
| `source_priority` | 380。医院自有站是院内遴选类公告的**原始发布方**，优先于豆包转载与聚合站；低于 CCGP/PLAP 的 400——后者抓完整详情页，hosp 只有搜索索引给的标题与摘要 |
| `content_access` | `public_partial`（有摘要）或 `metadata_only` |
| `date_authoritative` | **False**。`PublishTime` 是网页元数据，不是公告发布日，核实阶段需自行确认 |
| `retrieval_verified` | **False**。没抓详情页 |
| `source_fields.单位` | 由域名反查医院名填入，作为采购人候选，仍需核实阶段确认 |
| `lead_tier` | `precise` / `broad`，供核实阶段决定是否需要开清单 |

## 成本

| 配置 | 域名 | 调用/次 | 月成本 |
|---|---|---|---|
| `--min-db 1`（默认） | 369 | 38 | **11.4 元** |
| `--min-target 1` | 149 | 16 | 4.8 元 |

加上 doubao 主适配器的 9 元/月，检索层总成本约 20 元/月。CCGP 与 PLAP 免费。

## 已知限制

- **只能看到豆包索引到的部分**，不是医院站的全量公告。索引覆盖率实测 32%（509/1605 个域名有产出，其中 386 个有招采页）。
- **索引有延迟**，`PublishTime` 也不可靠，所以 `date_authoritative=False`。
- 覆盖面受限于普查快照，需按 hospital_sites.md 的季度普查刷新。

补全量的路子是**直接抓取**——索引里 1070 个 `s=1` 的域名可直连，且首页能找到招标栏目链接的约占 15%（实测样本）。那条路零调用成本、拿全量、不受索引延迟影响，但需要逐站发现栏目 URL 并维护。两条路重叠度不高，是互补关系，尚未实现。
