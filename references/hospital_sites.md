# 医院官网索引（hospital_sites.min.json.gz）

仅在维护医院站信源或诊断其召回时读取本文件。索引本体是 `data/hospital_sites.min.json.gz`，2127 家三级医院，30 KB。

**用途是驱动检索，不是补全字段。** 需要医院全名、等级、行政区划时用 `data/hospitals.min.json.gz`（50599 条全量库），两个索引互不替代。

## 为什么需要这个索引

CCGP 只收走政府采购流程的公告，PLAP 只覆盖军队采购。医院自己发布的**院内遴选、询比、议价、竞价、供应商征集、市场调研**这几类，两者结构上都拿不到——而这正是 IVD 试剂采购的高频形态。

2026-08-26 普查实测，医院站上捞到的原话：

```
四川大学华西医院  「神经性自身免疫性相关抗体检测试剂盒及配套设备」采购公告（第二轮）
                「和肽素（CPP）检测（化学发光法）试剂盒及配套设备」采购公告
南方医科大学南方医院  增城院区关于罗氏全自动生化免疫分析仪专用耗材供应商征集公告
成都大学附属医院    结核分枝杆菌特异性细胞免疫反应检测试剂比选采购公告
```

第一条正中本司品类，且不会出现在 CCGP 上。

## 字段

| 字段 | 含义 |
|---|---|
| `n` | 医院名称 |
| `lv` | 医院等级 |
| `h` | 官网域名，**含子域** |
| `s` | HTTP 可达性：1=ok 2=suspect 3=unknown 4=mismatch 5=dead |
| `db` | 豆包索引到的该域名招采公告数（普查快照，0=未索引到） |
| `tg` | 其中命中检验/试剂类信号的条数 |
| `bad` | 1=**不得进 Sites 白名单**（域名被抢注/过期/是第三方目录或政府门户） |
| `note` | 人工可读的状态说明 |

顶层另有 `manual_todo`：域名已失效但新官网未能自证的医院，附候选域名供人工确认。

## 关键：`s` 和 `db` 是两个独立信号，不要合并

**抓不到 ≠ 豆包索引不到。** 2026-08-26 交叉验证：

| HTTP 状态 | 豆包有招采产出 | 无产出 | 产出率 |
|---|---|---|---|
| ok | 343 | 741 | 32% |
| dead | 27 | 954 | 3% |
| suspect | 23 | 71 | 24% |
| unknown | 15 | 60 | 20% |
| mismatch | 1 | 124 | 1% |

`dead` 里有 27 个域名豆包仍有招采产出——南京市第一医院、蚌医大一附院、盐城市第三人民医院这些站是活的，只是反爬挡住了抓取器。**据 `s=5` 剔除会误杀这批。**

反过来 `ok` 里有 741 个豆包完全没索引——它们对白名单没用，但对未来的直抓适配器有用。

所以：
- **Sites 白名单**按 `db > 0` 选，不看 `s`
- **直抓适配器**按 `s == 1` 选，不看 `db`

## 源数据的已知问题

源表 `全国三级医院信息.xlsx` 是 AI 检索所得，2359 行。已修正：

**1. 200 行带 `[重复] ` 前缀**，去前缀后与正常行完全同名，已归并。

**2. 28 个域名已被医院弃用**，其中 17 个被抢注、11 个挂着「域名售卖」。被抢注的落点是体育直播站、股票配资站、TP 钱包下载页、软件站——**这类页面内容不可信，绝不能进白名单**。涉及的不乏大三甲：

```
温州医科大学附属第一医院   www.wyyy.cn        → 域名售卖
东莞市人民医院           www.dgph.cn        → 域名售卖
辽宁省妇幼保健院         www.lnfy.cn        → 域名售卖
杭州市萧山区第一人民医院    www.xshospital.com → 球友直播
沧州市人民医院           www.czrmyy.cn      → 江苏反诈网
武汉市黄陂区中医医院       www.hpzyyy.com     → TP钱包下载
```

其中 10 家已通过「豆包按院名检索 + HTTP 抓首页自证」修复（如 `山东省公共卫生临床中心 → www.sdgwlc.com`、`辽宁省妇幼保健院 → www.lnsfybjy.com`、`东莞市人民医院 → www.dgphospital.com`）。**其余 17 家未写入猜测值**，标 `bad=1` 并列在 `manual_todo` 里。

**3. 第三方医疗目录站被误当官网。** `zhuangshengsheng.com` 在源表里重复出现 8 次，是目录站不是医院。同类还有 `youlai.cn`、`99.com.cn`、`120ask.com`、`jiuyi120.com`。已按域名模式标 `bad=1`。

**4. 3 个 `.gov.cn` 落点**，其中 `成都锦力骨科医院 → www.chengdu.gov.cn` 是错填（成都市政府门户）；`邵武市立医院`、`罗定市中医院` 确实托管在政府子域，属正常。政府门户统一标 `bad=1`——它们的招采公告已由 CCGP 覆盖，进白名单是重复。

## 维护流程

### 季度普查（约 2 元）

重跑域名索引普查，刷新 `db` / `tg`：每 20 个域名一批（`Sites` 上限），全量 ~107 批 × 2 个宽词（`招标`、`试剂`）≈ 214 次调用。

医院采购周期长，`db=0` 不代表这家医院永远不发招标——**普查用于扩充白名单，不用于永久剔除**。

### 年度可达性校验（免费）

重抓全部首页，刷新 `s` 与坏站标记。两个必须注意的实现坑，第一轮都踩过：

1. **URL 含中文或 IDN 域名时 urllib 抛 `UnicodeEncodeError: 'latin-1'`** —— 首轮 356 家被误判成 dead。必须对 host 做 `.encode('idna')`、对 path 做 percent-encode。
2. **HTML 实体未解码** —— `&#x7ECD;&#x5174;...` 就是「绍兴」，首轮把 9 家正确的站判成了 mismatch。取 `<title>` 后必须 `html.unescape()`。

判定用「医院名词元 + 医疗机构词」，不要用全名精确匹配——医院常用简称、分院名、「XX大学附属」等价名（`德阳市第六人民医院` = `德阳市老年病医院`）。

### 域名修复

对判为过期/抢注的域名：豆包按医院名检索（**院名无空格，单词 Query 正好适用**）→ 过滤第三方目录站 → HTTP 抓首页自证。

**只接受能自证的域名，宁可留空也不写猜测值。** 首轮 25 家里只有 10 家通过自证，其余进 `manual_todo`；候选域名一并记下，人工确认只需点开看一眼。
